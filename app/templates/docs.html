Introduction

CardX exposes a REST API so developers can create, manage and embed digital business cards inside their own products. Base URL:

{{ request.url_root }}api/v1

Authentication

Every request must include your API key as a Bearer token. Generate keys from Dashboard → API Keys.

Authorization: Bearer cx_live_xxxxxxxxxxxxxxxxxxxx

Cards

POST  /cards
curl -X POST {{ request.url_root }}api/v1/cards \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Ahmed Benali",
    "title": "CEO",
    "company": "ABC",
    "phone": "+213555000000",
    "email": "ahmed@example.com",
    "template": "executive"
  }'

Response 201:

{
  "id": "card_9f2a1c4b",
  "username": "ahmedbenali",
  "url": "{{ request.url_root }}c/ahmedbenali",
  "qr_code": "{{ request.url_root }}c/ahmedbenali/qr.png",
  "status": "active"
}
GET /cards
GET /cards/:id
PUT /cards/:id
DELETE /cards/:id

Templates

Pass any of these slugs in the template field: minimal, executive, corporate, luxury, gradient, glass, creative, dark, elegant, professional.

QR Codes

Every card automatically gets a permanent QR code that always points to the card URL (it never changes even if you edit the card):

GET /c/{username}/qr.png

Contacts

POST /api/v1/cards/:id/contact
→ { "vcard_url": ".../c/{username}/vcard.vcf" }

Analytics

GET /api/v1/cards/:id/analytics
→ { "stats": { "view": 128, "qr_scan": 14, "click": 41, "contact_saved": 6 } }

Webhooks

Register a webhook URL from Dashboard → Webhooks. CardX sends a signed POST with header X-CardX-Signature (HMAC-SHA256 of the body using your webhook secret) for these events:

card.created · card.updated · card.viewed
qr.scanned · contact.saved · link.clicked

Errors

401 invalid_api_key
402 plan_limit_reached
403 account_suspended
404 not_found
429 rate_limit_exceeded

Rate Limits

Each plan has a daily request cap (see Pricing). Exceeding it returns 429.

SDKs

A thin wrapper is all you need until official SDKs ship — the REST API is the source of truth. Example (JavaScript):

async function createCard(apiKey, data) {
  const res = await fetch("{{ request.url_root }}api/v1/cards", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${apiKey}`,
      "Content-Type": "application/json"
    },
    body: JSON.stringify(data)
  });
  return res.json();
}

Python:

import requests
requests.post(
    "{{ request.url_root }}api/v1/cards",
    headers={"Authorization": f"Bearer {api_key}"},
    json={"name": "Ahmed Benali", "title": "CEO"},
)

Embed a card in any site:

<iframe src="{{ request.url_root }}c/ahmedbenali" width="380" height="720"></iframe>
